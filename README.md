# 📘 UKL API Project

Proyek ini adalah API sederhana berbasis **Node.js**, **Express**, dan **Prisma** yang dibuat untuk keperluan UKL (Uji Kompetensi Keahlian).  
Project ini dirancang agar mudah dipahami oleh pelajar yang sedang belajar membuat REST API menggunakan JavaScript.

---

## 🚀 Cara Menjalankan

1. Pastikan sudah menginstal **Node.js** di komputer.
2. Buka terminal pada folder project.
3. Jalankan perintah berikut untuk menginstal semua dependency:
   ```bash
   npm install
